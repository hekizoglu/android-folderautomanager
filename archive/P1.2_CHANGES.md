# P1.2: ClassificationReviewScreen Pending Count Badge

## Task
Implement pending classification count badge in HeroDashboardPage that:
1. Shows real-time count of pending classifications
2. Displays badge only when count > 0
3. Tap navigates to ClassificationReviewScreen

## Files Modified

### 1. AppDao.kt
**File:** `app/src/main/java/com/armutlu/apporganizer/data/local/AppDao.kt`

Added Flow-based query to observe pending classification count:
```kotlin
@Query("""
    SELECT COUNT(*) FROM apps
    WHERE classificationReviewState = 'PENDING'
        AND isSystemApp = 0
        AND (reviewSnoozedUntil = 0 OR reviewSnoozedUntil <= :now)
""")
fun observePendingClassificationCount(now: Long = System.currentTimeMillis()): Flow<Int>
```

### 2. AppRepository.kt
**File:** `app/src/main/java/com/armutlu/apporganizer/data/repository/AppRepository.kt`

Added repository method wrapping DAO:
```kotlin
fun observePendingClassificationCount(): Flow<Int> {
    return appDao.observePendingClassificationCount()
        .distinctUntilChanged()
        .flowOn(Dispatchers.IO)
}
```

## Architecture

```
Room DB (pending classification count query)
    ↓
AppDao.observePendingClassificationCount() [Flow<Int>]
    ↓
AppRepository.observePendingClassificationCount() [Flow<Int>]
    ↓
LauncherViewModel.pendingClassificationsCount [StateFlow<Int>]
    ↓
HomeScreen (collects state)
    ↓
DashboardUiState.pendingClassificationCount
    ↓
SmartDashboardPage
    ↓
HeroDashboardPage + PendingClassificationBadge (UI display)
    ↓
Tap → onOpenClassificationReview callback → navigate to ClassificationReviewScreen
```

## Real-time Updates

- Query uses `distinctUntilChanged()` to emit only when count actually changes
- `SharingStarted.Eagerly` ensures badge updates whenever pending count changes
- No manual refresh needed - reactive database subscription handles it

## UI Behavior

- Badge appears only when count > 0
- Positioned after HeroSearchCard, before SmartAccessCard
- Uses Material 3 secondaryContainer styling (consistent with system theme)
- Shows count in circle badge on right side
- Tap triggers navigation to ClassificationReviewScreen
