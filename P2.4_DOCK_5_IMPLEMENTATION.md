# P2.4: Dock 5. Slot Implementasyonu (CATEGORY_DEFAULT)

## Özet

#### 2. Yeni Method: `resolveDefaultCategory()`
```kotlin
/**
 * Resolves the device's default app from CATEGORY_DEFAULT for the 5th dock slot.
 * Falls back to null if no default is found or if the app is already in the first 4 slots.
 */
private fun resolveDefaultCategory(context: Context): String? {
    val intent = Intent(Intent.ACTION_MAIN)
        .addCategory(Intent.CATEGORY_DEFAULT)
    val pkg = context.packageManager
        .resolveActivity(intent, android.content.pm.PackageManager.MATCH_DEFAULT_ONLY)
        ?.activityInfo
        ?.packageName
    return pkg?.takeIf { context.packageManager.getLaunchIntentForPackage(it) != null }
}
```

**Mantığı:**
- `Intent.ACTION_MAIN` + `Intent.CATEGORY_DEFAULT` kombinasyonu Android'in "default app" mekanizmasını sorguladığı standart yoldur
- `PackageManager.MATCH_DEFAULT_ONLY` — implicit intent'ler için cihazın özel atamalarını geri döndürür
- `getLaunchIntentForPackage()` check — resolved paket gerçekten launch edebilir mi kontrol eder
- `takeIf` — null ya da non-launchable ise null geri döner

#### 3. resolveDefaults() güncellendi
```kotlin
private fun resolveDefaults(context: Context): List<String> {
    val pm = context.packageManager
    val dialer = resolveDefaultApp(context, Intent(Intent.ACTION_DIAL, Uri.parse("tel:")))
    val sms = resolveDefaultApp(context, Intent(Intent.ACTION_SENDTO, Uri.parse("smsto:")))
    val camera = DEFAULT_SLOTS[2].firstOrNull { pkg -> pm.getLaunchIntentForPackage(pkg) != null }
    val browser = resolveDefaultBrowser(context)
    val slot5 = resolveDefaultCategory(context)  // ← YENİ

    return listOfNotNull(dialer, sms, camera, browser, slot5)  // ← slot5 eklendi
        .distinct()
        .take(MAX_SLOTS)
        .ifEmpty {
            DEFAULT_SLOTS.mapNotNull { candidates ->
                candidates.firstOrNull { pkg -> pm.getLaunchIntentForPackage(pkg) != null }
            }
        }
}
```

**Akış:**
1. Slot 1-4 resolve edilir (sabit amaçlar: tel, SMS, kamera, tarayıcı)
2. Slot 5 `resolveDefaultCategory()` ile CATEGORY_DEFAULT'tan döner
3. Döner listeler `listOfNotNull` → removes null values
4. `.distinct()` → duplicate apps removed (5 slot'tan fazla liste varsa de-dup)
5. `.take(MAX_SLOTS)` → exactly 5 slot
6. `.ifEmpty` fallback → hiçbir app bulunmazsa DEFAULT_SLOTS cascade'i çalışır

## Tasarım Kararları

### Neden CATEGORY_DEFAULT?
- **Standar Android davranışı** — RoleManager tarafından yönetilen sistem-level default
- **Hiç random değil** — kullanıcının tercihine dayanır
- **Her cihaz farklı** — cihaz üreticisinin/kullanıcının konfigürasyonuna göre dinamik
- **En güvenilir** — `PackageManager.MATCH_DEFAULT_ONLY` Android'in resmi mekanizması

### Neden boş fallback?
- Slot 5 bulunamadığında boş kalır (null → removed by listOfNotNull)
- Daha iyisi: cihaz hiçbir default app atamamış (nadir edge case)
- Kullanıcı her zaman DockEditSheet'ten manuel ekleyebilir

### Duplicate kontrol
- `.distinct()` — zaten 4 slot'ta olan app'in 5. slot'ta tekrarlanması engeller
- Örnek: dialer default app ise, slot 1 + slot 5 would both be dialer → distinct() 1'i tuttuğu için sadece slot 1 uygulanır
