# AppOrganizer Hata Düzeltme Görevi

## Rol

Sen kıdemli Android/Kotlin ve Jetpack Compose mühendisisin. AppOrganizer uygulama çekmecesindeki doğrulanmış dal tutarsızlığını en küçük güvenli değişiklikle düzelt.

## Doğrulanmış Sorun

- **Bulgu kimliği:** FINDING-001
- **Önem:** Orta
- **Güven seviyesi:** %98
- **Kategori:** Compose UI / mantık hatası / görünürlük tutarsızlığı
- **Belirti:** Uygulama çekmecesi A–Z sıralamasındayken “Son kullanılanlar”, “Favoriler” ve “Son bildirimler” üst satırları görünür. Kullanıcı sıralamayı Akıllı, Kullanım, Boyut, Yükleme tarihi veya ters sıralamalardan birine aldığında bu satırlar kaybolur. “Bugün yüklenenler” satırı ise düz liste dalında ayrıca render edildiği için görünmeye devam eder.
- **Kullanıcı etkisi:** Kullanıcı, sıralama tercihini değiştirince çekmecedeki hızlı erişim bölümlerinin ayar kapatılmış gibi kaybolduğunu görür. Bu davranış sıralama seçimi ile ilgisizdir ve özelliklerin güvenilirliğini düşürür.

## Kanıt

### 1. State üretimi

Dosya:
`app/src/main/java/com/armutlu/apporganizer/presentation/ui/launcher/AllAppsDrawerUtils.kt`

`rememberDrawerData()` içinde `grouped` yalnızca şu durumda oluşturuluyor:

```kotlin
if (sortMode == AllAppsSortMode.ALPHA && searchQuery.isBlank()) {
    // groupBy
} else emptyMap()
```

Dolayısıyla A–Z dışındaki tüm sıralama türlerinde `state.grouped.isEmpty()` olur ve düz liste dalı çalışır.

### 2. Gruplu liste dalı

Dosya:
`app/src/main/java/com/armutlu/apporganizer/presentation/ui/launcher/AllAppsDrawer.kt`

`if (state.grouped.isNotEmpty())` dalı şunları render ediyor:

- `DrawerRecentFavSection`
- `DrawerRecentNotificationSection`
- `DrawerTodayInstalledSection`

### 3. Düz liste dalı

Aynı dosyada `else` dalı yalnızca şunu render ediyor:

- `DrawerTodayInstalledSection`

Şunlar eksik:

- `DrawerRecentFavSection`
- `DrawerRecentNotificationSection`

Bu asimetri nedeniyle sıralama değişiminde özellikler kayboluyor.

## Kök Neden

Çekmece içeriği iki ayrı LazyColumn dalına bölünmüş. Yeni üst bölümler alfabetik-gruplu dala eklenmiş, fakat düz liste dalına eşit biçimde eklenmemiş. “Bugün yüklenenler” özelliği eklenirken iki dala da konmuş olması, diğer iki bölümün unutulduğunu daha da güçlü biçimde gösteriyor.

## Sınırlar

- Yeni özellik ekleme.
- Sıralama davranışını değiştirme.
- `rememberDrawerData()` içindeki gruplama mantığını değiştirme.
- Navigation, ViewModel, Room, AppPrefs veya veri modeline dokunma.
- İlgisiz refactor yapma.
- UI tasarımını değiştirme.
- versionCode/versionName artırma; bu günlük hata düzeltme doğrulamasıdır.

## İstenen Çözüm

1. `AllAppsDrawer.kt` içindeki düz liste `else` dalının başına, gruplu dal ile aynı koşulları ve aynı composable çağrılarını ekle:
   - `DrawerRecentFavSection`
   - `DrawerRecentNotificationSection`
2. Parametreleri gruplu dal ile birebir aynı tut:
   - `recentApps.take(4)`
   - `favoriteApps.take(4)`
   - `recentNotificationApps.take(4)`
   - `state.iconPackPkg`
   - mevcut click ve long-click callback’leri
3. LazyColumn item key’leri gruplu daldakilerden farklı ve stabil olsun. Öneri:
   - `recent_fav_section_flat`
   - `recent_notification_apps_section_flat`
4. `searchQuery.isEmpty()` şartını koru; arama sonuçlarında bu bölümler görünmemeli.
5. Feature toggle şartlarını aynen koru.
6. Mevcut `today_installed_apps_section_flat` bloğuna dokunma.

## Beklenen En Küçük Kod Şekli

Düz liste `LazyColumn` başlangıcında yaklaşık olarak:

```kotlin
if (searchQuery.isEmpty() &&
    (recentAppsEnabled && recentApps.isNotEmpty() ||
        favoritesEnabled && favoriteApps.isNotEmpty())
) {
    item(key = "recent_fav_section_flat") {
        DrawerRecentFavSection(
            recentApps = if (recentAppsEnabled) recentApps.take(4) else emptyList(),
            favoriteApps = if (favoritesEnabled) favoriteApps.take(4) else emptyList(),
            iconPackPkg = state.iconPackPkg,
            onRecentAppClick = onRecentAppClick,
            onFavoriteAppClick = onFavoriteAppClick,
            onAppLongClick = onAppLongClick,
        )
    }
}

if (searchQuery.isEmpty() &&
    recentNotificationAppsEnabled &&
    recentNotificationApps.isNotEmpty()
) {
    item(key = "recent_notification_apps_section_flat") {
        DrawerRecentNotificationSection(
            apps = recentNotificationApps.take(4),
            iconPackPkg = state.iconPackPkg,
            onAppClick = onAppClick,
            onAppLongClick = onAppLongClick,
        )
    }
}
```

Bu kodu körlemesine kopyalama; dosyanın güncel halini okuyup parametre adlarını doğrula.

## Kabul Kriterleri

- A–Z dışındaki tüm sıralama modlarında etkin hızlı erişim bölümleri görünür.
- Arama modunda bu bölümler görünmez.
- Feature toggle’lar doğru çalışır.
- Hiçbir sıralama veya liste davranışı değişmez.
- Compile, unit test, lint ve assembleDebug başarılıdır.
- Emülatörde crash veya yerleşim taşması yoktur.
- Değişiklik yalnızca gerekli `AllAppsDrawer.kt` satırlarıyla sınırlıdır.

## Rollback

Düz liste dalına eklenen iki item bloğunu kaldırmak yeterlidir. Veri modeli veya kalıcı veri değişmediği için ek rollback/migration gerekmez.
