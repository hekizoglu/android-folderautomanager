# Günlük Denetim Bulgusu — 2026-08-09 — AppPrefs sıralama ayarı FolderTile önizlemesine reaktif bağlanmıyor

## Önem
Orta. Veri kaybı veya crash riski yok; ancak kullanıcı All Apps sıralama modunu değiştirdikten sonra ana ekrandaki klasör önizleme ikonları eski sırada kalabiliyor.

## Kanıt
`app/src/main/java/com/armutlu/apporganizer/presentation/ui/launcher/FolderTile.kt` içinde:

```kotlin
val folderSortMode = remember(context) {
    val saved = AppPrefs.getFolderSortMode(context)
    AllAppsSortMode.entries.firstOrNull { it.name == saved } ?: AllAppsSortMode.ALPHA
}
```

Aynı dosyada önizleme:

```kotlin
val previewApps = remember(folder.apps, folderSortMode) {
    folder.apps.sortedByMode(folderSortMode).take(4)
}
```

`HomeScreen.kt` içindeki `SharedPreferences.OnSharedPreferenceChangeListener` güncel ayarların çoğunu dinliyor; ancak `KEY_ALL_APPS_SORT_MODE` için bir state güncellemesi yok. Bu nedenle kullanıcı ayarı değiştirdiğinde `folderSortMode` state'i değişmiyor. Başka bir recomposition olsa bile `remember(context)` aynı değeri koruduğu için önizleme eski sıralamada kalıyor.

## Kök neden
SharedPreferences'ta yazılan `KEY_ALL_APPS_SORT_MODE` değeri, FolderTile'ın Compose state zincirine taşınmamış. Yazma → okuma → tüketme zincirinde tüketim yalnız ilk composition anında gerçekleşiyor.

## Kullanıcı etkisi
- All Apps sıralaması yeni moda geçer.
- Klasör içine girildiğinde uygulamalar yeni sıralamada görünebilir.
- Ana ekrandaki 2x2 mini ikon önizlemesi eski sıralamada kalabilir.
- Kullanıcı aynı klasörde iki farklı sıralama görür; ürün tutarlılığı bozulur.

## Neden bu denetim turunda otomatik düzeltilmedi
Gradle/ADB doğrulama ortamı bu çalışmada erişilebilir değildi. UI davranışını değiştirecek bir kod değişikliği, `compileDebugKotlin`, `testDebugUnitTest`, `lintDebug`, `assembleDebug` ve emülatör screenshot doğrulaması olmadan main'e yazılmadı.

## Uygulama talimatı
Başka bir yapay zekâ aşağıdaki çözümü uygulasın:

1. `HomeScreen.kt` içindeki mevcut AppPrefs listener'a `AppPrefs.KEY_ALL_APPS_SORT_MODE` case'i ekle.
2. HomeScreen seviyesinde `var folderSortMode by remember { mutableStateOf(...) }` state'i oluştur veya mevcut ayar state düzenine uyacak eşdeğer reaktif state ekle.
3. Bu state'i `HomePagerHost`/`FolderGridPage`/`FolderTile` çağrı zincirinden geçirerek `FolderTile` içinde doğrudan `AppPrefs.getFolderSortMode(context)` okumayı kaldır.
4. `FolderTile` imzasına `folderSortMode: AllAppsSortMode` ekle ve `previewApps` hesabını yalnız `folder.apps` + `folderSortMode` ile türet.
5. Mevcut `AllAppsSortMode` parse fallback'i korunmalı; geçersiz string `ALPHA` olmalı.
6. Aynı ayarın AllAppsDrawer sıralamasını etkileyen mevcut kodu değiştirme; tek doğruluk kaynağı korunmalı.
7. Yeni dependency, migration veya navigation değişikliği yapma.
